# Bank On It Java Lab

Part 1 Java Lab

## Algorithm

   * Make the customer menu:
   * show the options
   * ask the user to pick a number
   * give back what they picked

   * customer menu:
   * pick = show the customer menu
   * while pick is not 0:
   * if pick is 1, go to the account menu for checking
   * else if pick is 2, go to the account menu for savings
   * else if pick is 3, say "Changing PIN..."
   * else say "Please enter a number from 0 to 3."
   * pick = show the customer menu again

   * Account menu
   * say the account name
   * pick = nothing yet
   * while pick is not 0
   * show options
   * ask the user to pick a number
   * 1, say "Checking balance..."
   * 2, say "Making a deposit..."
   * 3, say "Making a withdrawal..."
   * not 0, say "Please enter a number from 0 to 3"
